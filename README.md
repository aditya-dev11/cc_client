# College Connect 🎓

An elite, professional networking platform for alumni and students. Built with React and Firebase.

## 🌟 Key Features
*   **Professional Discovery**: Search and filter alumni by industry, role, and department.
*   **Mentorship Networks**: Connect with senior alumni for career guidance.
*   **Dynamic Groups**: Join department-specific clusters for project collaboration and networking.
*   **Premium Tools**: Integrated with the `react-resume-ai` and `react-feedback-report-dialog` professional SDKs.

## 🛠️ Technology Stack
*   **UI Framework**: React 18+
*   **Design System**: Material UI (Custom Royal Blue Theme)
*   **Backend**: Firebase (Firestore, Auth, Analytics)
*   **AI**: Gemini Pro (via library integration)

## 🚀 Getting Started
1. Clone the repository.
2. Run `npm install`.
3. Configure your `.env` with Firebase credentials.
4. Run `npm run dev` to launch the professional portal.

## 📂 Project Structure
*   `/src/components/Layout`: Modern Glassmorphism Shell.
*   `/src/context`: Auth & Global State.
*   `/src/services`: Specialized Firestore integration.
*   `/src/pages`: Fresh, high-conversion networking views.
